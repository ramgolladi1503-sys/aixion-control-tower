### PostgreSQL credential issuance and introspection — 2026-10-22

- Credential issuance now uses the PostgreSQL trust/event repositories when the complete app-bound trust bundle is present. It row-locks the scoped lease, checks active/unexpired state and the lease receipt signature, limits credential expiry to the lease expiry, stores only a SHA-256 token hash, and commits the grant with a `CREDENTIAL_GRANT_ISSUED` hash-chained event. External GitHub App/OIDC broker grants remain explicitly unimplemented.
