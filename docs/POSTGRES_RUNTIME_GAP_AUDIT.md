## Executive finding

The diagnostic probe setting alone does not activate PostgreSQL routes. When `postgres_auth_enabled` is explicitly selected, the FastAPI lifespan opens the PostgreSQL runtime, verifies its migration ledger, binds the app-state repository references to that one bundle, and restores the prior references at shutdown. A real-lifespan PostgreSQL integration test now covers Antigravity approval creation, notification inbox/device registration, reviewer decision, connector polling and one-time consume, replay denial, and absence of SQLite projections for those records. This verifies that critical vertical locally; it does not prove all routed surfaces use PostgreSQL. Process-global SQLite writers and unsupported paths remain, so readiness reports `database_backend="mixed"`, keeps `application_store_ready=false`, and the production startup guard remains active. Isolated repository suites alone still do not establish a complete application store.
