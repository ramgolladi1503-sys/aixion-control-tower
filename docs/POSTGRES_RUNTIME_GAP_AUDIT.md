## Executive finding

The application cannot safely activate PostgreSQL by toggling the current probe setting. The FastAPI lifespan opens a PostgreSQL pool and verifies its migration ledger when `AIXION_POSTGRES_RUNTIME_PROBE_ENABLED` is enabled, but routes and workers continue using the process-global `store` and module-level SQLite repositories. Readiness reports `database_backend="sqlite"` for this reason. A passing PostgreSQL repository suite proves those repositories in isolation; it does not prove that the routed application uses them.

The PostgreSQL auth repository has operations for bootstrap registration, invite registration, verification, invitations, account roles/deletion, user lookup, and sessions. This is scoped evidence for the auth/session path only; it does not cover every app route, all auth operations across independent processes, or production startup.
